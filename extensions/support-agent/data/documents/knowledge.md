# 星桥云办公客服业务知识手册（模拟资料）

本手册逐条转换自 data/knowledge.json，仅增加标题和来源标记，不补充或改写业务规则。

资料描述的是模拟产品，不代表本机知识库导入工具支持文中所有文件类型或上传限额。

## KB-001 账号登录失败与密码重置

来源：模拟产品手册 / 账号管理 / 登录与重置

星桥云办公账号连续输错密码5次后会锁定15分钟。先确认邮箱大小写与前后空格，使用忘记密码入口发送重置邮件；链接有效期30分钟且只能使用一次。没有收到邮件时检查垃圾邮件和企业邮件网关。客服不会索取用户密码、验证码或重置链接。企业单点登录SSO账号请使用企业身份提供商的重置流程。

## KB-002 SSO 单点登录 SAML 配置排查

来源：模拟产品手册 / 身份集成 / SAML

管理员配置SAML单点登录时需校验ACS回调地址、Entity ID与身份提供商证书。出现Invalid audience时比较Entity ID；出现签名验证失败时检查证书到期时间及是否导入最新证书。客户端与服务端时间偏差应小于5分钟。修改SSO配置前保留一个本地管理员应急账号，不应关闭全部身份校验。

## KB-003 成员邀请与席位不足

来源：模拟产品手册 / 组织管理 / 邀请成员

只有组织管理员可以邀请成员。邀请链接有效期72小时，过期后需从成员管理重新发送。显示席位不足时，先检查当前订阅席位与已激活、待邀请成员总数，撤销不用的邀请可释放预留席位。升级席位需要管理员在订阅管理确认，不能通过客服工单自动扣费。

## KB-004 文件上传限制与格式错误

来源：模拟产品手册 / 文件 / 上传限制

标准版单个文件上传上限100MB，支持PDF、DOCX、TXT、CSV和XLSX。文件超过限制时应压缩或分拆后上传；受密码保护的PDF需由持有人先解除保护。遇到415 Unsupported Media Type时检查实际文件格式与扩展名是否一致，不能仅修改扩展名。上传超时可检查代理和网络后重试。

## KB-005 知识库索引排队与扫描 PDF

来源：模拟产品手册 / 知识库 / 索引状态

文件上传完成后进入索引队列，一般在5分钟内可检索。超过15分钟仍显示处理中时记录文件ID、上传时间、文件类型和组织ID，再创建排查工单。扫描PDF只有图片时需先执行OCR文字识别，否则无法提取正文。删除旧文件后重新上传会产生新文件ID，应等待新索引完成再测试检索。

## KB-006 API 请求 429 与限流重试

来源：模拟开发指南 / API / 限流

星桥开放API按组织限流，标准版每分钟120次请求。收到HTTP 429时先读取Retry-After响应头并等待指定时间；缺失该响应头时使用带随机抖动的指数退避，最多重试3次。不要并发立即重试所有请求。写操作重试必须复用同一幂等键，避免重复创建业务记录。

## KB-007 API 401 与密钥轮换

来源：模拟开发指南 / API / 认证

HTTP 401表示缺失、错误或过期的API凭证。API请求需使用Authorization: Bearer格式，不要将密钥放在URL查询参数。密钥泄露时立即撤销旧密钥、创建新密钥并更新应用环境变量；轮换完成后检查旧密钥已不可用。不要把完整密钥粘贴到工单、聊天或日志中。

## KB-008 工作区 403 与资源访问权限

来源：模拟产品手册 / 权限 / 资源访问

HTTP 403表示账号已认证但不具备资源权限。先确认当前组织和工作区，再由资源所有者检查成员角色及文件分享范围。查看者不能编辑或删除文件；成员不能修改组织计费设置。禁止通过修改user_id、猜测资源编号或借用其他人的API Key绕过权限。权限申请需要组织管理员确认。

## KB-009 Webhook 回调签名与重复投递

来源：模拟开发指南 / 事件 / Webhook

Webhook接收方应校验X-Orbit-Signature签名和时间戳，时间差超过5分钟拒绝处理。签名由原始请求体计算，重新序列化JSON会导致验签失败。接收端在3秒内返回2xx；暂时失败会触发最多5次重投。使用event_id唯一约束去重，重复事件返回成功但不重复执行业务。

## KB-010 账单、发票与订阅变更

来源：模拟产品手册 / 计费 / 账单与发票

组织管理员可在账单中心下载已付款订单的电子发票。开票信息包含公司名称、税号、接收邮箱，提交前应自行核对。发票通常在付款后2个工作日可下载。订阅升级和取消由管理员在计费页面确认；客服Agent只可说明流程和创建咨询工单，不可代替用户付款或承诺退款。

## KB-011 误删除文件恢复与保留期

来源：模拟产品手册 / 数据管理 / 回收站

星桥工作区误删文件会进入回收站，保留30天。文件所有者或组织管理员可在回收站恢复，恢复后需等待索引重新建立。超过30天自动永久删除，无法通过普通恢复功能找回。永久删除前需二次确认；客服不能保证已经永久删除的数据可以恢复。

## KB-012 工单优先级与响应说明

来源：模拟服务手册 / 工单 / 优先级

high高优先级用于多用户无法登录、核心工作区完全不可用等广泛影响；normal普通优先级用于单用户功能异常、索引失败或一般咨询；low低优先级用于功能建议与非紧急问题。该演示环境不提供真实服务SLA，也不承诺固定修复时间。填写优先级时说明影响范围，不能将用户的所有问题自动升级为最高优先级。

## KB-013 创建工单所需信息与人工确认

来源：模拟服务手册 / 工单 / 安全提交

创建工单应收集问题标题、现象、发生时间、影响范围、错误码和已尝试的排查步骤，避免收集密码、验证码或完整API Key。Agent只能创建草稿，用户必须打开确认页并使用独立业务账号登录，核对内容后点击确认并创建。聊天中的同意或模型填写approved=true不能替代确认页授权。草稿默认30分钟过期。

## KB-014 网络超时、请求重试与幂等

来源：模拟开发指南 / 可靠性 / 幂等请求

写请求发生超时并不代表服务端没有执行。先查询原请求状态，再决定是否重试。创建草稿时同一业务请求须复用request_id和原始内容；相同request_id配不同内容会返回409。确认页重复提交同一草稿只产生一张工单。用户修改内容属于新请求，应取消旧草稿后使用新的request_id。

## KB-015 CSV 导出乱码与时区

来源：模拟产品手册 / 报表 / 导出

CSV报表使用UTF-8编码。Windows Excel直接打开出现中文乱码时，使用数据导入并明确选择UTF-8编码，或选择产品的XLSX导出格式。报表中的时间戳采用UTC；北京时间为UTC+8，比较日志与报表时先统一时区。导出仅包含当前账号有权访问的数据。

## KB-016 状态查询与排障证据收集

来源：模拟服务手册 / 排障 / 信息收集

提交问题前记录错误发生时间及所用时区、客户端版本、错误码、请求trace_id和可重复的操作步骤。trace_id用于关联一次请求的审计记录，不包含用户密码。查询已有工单时仅返回当前业务账号的工单；若找不到工单，应检查是否使用了相同业务账号，不能借用别人的凭证查询。
